## Future Interns – Task 01 | Data Science & Analytics

### 👩‍💻 Intern
A Bowthya Sree

### 🎯 Objective
Analyze e-commerce sales data to identify:
- Revenue trends
- Top-selling products
- Country-wise sales performance
- Customer purchasing patterns

### 🛠️ Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

### 📈 Key Insights
- Q4 generated highest revenue
- UK contributed majority of sales
- Seasonal sales spikes observed
- Top products dominated revenue

### 💡 Recommendations
- Expand international marketing
- Increase inventory before Q4
- Create loyalty programs
- Run promotions during low-sales periods
